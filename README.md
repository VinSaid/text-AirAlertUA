# AirAlert

Простий застосунок для Android: сповіщення про повітряну тривогу у вибраній області.
Дані: https://ubilling.net.ua/aerialalerts/ (неофіційний посередник, може бути затримка).
Не покладайтеся лише на застосунок: слухайте сирени та офіційні канали.

APK збирається автоматично в GitHub Actions (вкладка Actions → останній запуск → Artifacts).
